# Task Manager Fullstack

Aplicación fullstack desarrollada como proyecto práctico de preparación para entrevistas de Software Developer.

## Stack

### Frontend

- Flutter
- Dart
- GetX
- Dio

### Backend

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- Alembic

### Base de datos

- PostgreSQL

### Autenticación

- JWT

## Arquitectura

Flutter:

View → GetX Controller → Repository → Service → Dio → REST API

Backend:

Route → Service → Repository → SQLAlchemy → PostgreSQL
